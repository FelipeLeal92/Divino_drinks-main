# Código histórico

`legacy-script.js` é a versão anterior das interações do site. O código ativo é `public/js/main.js`.

`sqlite/` contém o esquema e a inicialização antigos, preservados como referência. O servidor ativo utiliza `src/store.js` com JSON. Esses scripts não são chamados pelos comandos npm e não devem ser executados sobre os dados atuais.
